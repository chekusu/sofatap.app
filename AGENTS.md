# Sofatap website

This standalone repository contains the Sofatap public website at its root. The brand is **Sofatap**, one word; `SofaTap` appears only in release file names and other compatibility identifiers. Product source lives in chekusu/sofatap; treat it as read-only reference and do not change that repository from here.

Product facts on the site must match the product source at the commit recorded in README.md and its published releases; verify a newer commit before changing claims. Keep development-source features clearly separate from the published downloads, and label illustrations and previews as such. All twelve language pages share one template; change every string file in src/i18n/ together (scripts/locales.mjs lists the languages). Commit verified work locally. Do not push, write to GitHub, deploy, publish previews, send notifications, or change credentials or service configuration unless the repository owner has directly authorized it.

Keep private reports, local machine paths, inbox records, credentials, pairing codes, runtime files, and browser caches out of this repository. Public files contain only product content and repository-relative documentation.
